# 介绍

vuEPG 是一个 Vue 插件，用来管理大屏（TV、IPTV、机顶盒、车机等）网页中的**遥控器焦点**。

在大屏上，用户没有鼠标，只能用遥控器的方向键、确定键和返回键操作。你需要回答三个问题：

1. 哪些元素可以获得焦点？
2. 按下某个方向键时，焦点应该移动到哪里？
3. 按下确定键、返回键时，应该发生什么？

vuEPG 用两个指令和少量 API 回答了这三个问题：

- 用 `v-epg-item` 标记可获得焦点的元素，用 `v-epg-group` 把它们组织成分组；
- 方向键按元素的**真实位置**自动计算下一个焦点，组内优先、逐层向外；
- 确定键模拟点击当前焦点，返回键调用你注册的返回处理函数。

## 特性

- **空间导航**：不需要手写跳转关系，布局变了导航自动跟着变。
- **分组与默认焦点**：进入一个分组时，焦点落在指定的默认元素上。
- **可靠的失效处理**：导航会跳过被卸载、隐藏（`v-show`、`display: none`、KeepAlive）或禁用的目标；焦点元素被卸载或隐藏后，下一次方向操作会在原分组内恢复。
- **可选自动滚动**：滚动列表可以通过分组的 `scroll` 选项让焦点元素保持可见。
- **原生 DOM 事件**：`epg-focus`、`epg-blur`、`epg-enter`、`epg-leave` 与方向事件都是标准 `CustomEvent`。
- **Vue 2.7 与 Vue 3 通用**：没有 vue-demi，没有运行时依赖。
- **老设备友好**：产物为 ES2015，按键识别兼容只提供 `keyCode` 的老旧机顶盒浏览器。更旧的 ES5 设备还需转译与运行时 API 支持，见 [环境要求](./getting-started#环境要求)。
