# 常见问题

## 需要替换已有组件吗

不需要。vuEPG 在现有 DOM 上用指令标记焦点项和分组，焦点样式由页面自己控制。普通按钮继续用 `@click` 处理确定操作。

如果已有组件封装了根元素，可在适当的 DOM 元素上添加指令；Vue 2.7 监听组件根元素的焦点事件时需要 `.native`，见[事件](./events)。

## 支持哪些输入方式

内置键盘和遥控器方向、确定、返回映射。手柄、虚拟控制器和原生回调可通过 `navigate()`、`back()` 等逻辑 API 接入；API 接入不需要合成键盘事件。见[原生按键接入](./native-bridge)。

## Android 4.x 等运营商存量盒子怎么接入

使用 Vue 2.7，将应用和依赖一起转译成 ES5，并补齐所需语言及 DOM API。[旧设备接入指南](./legacy-webview)提供可运行的工程、真机开发命令和排错步骤。

## 为什么 Vite 真机开发会白屏

旧 WebView 无法执行 Vite 的原生 ESM 开发入口。示例保留 webpack 真机开发入口；Vite 用于现代浏览器。两者的构建与运行路径见 [Android 4.x 接入](./legacy-webview#为什么保留-webpack-开发入口)。

## 为什么进入另一个分组没有落在最近的元素上

跨组导航先选择目标组，再按该组的默认入口进入。只在需要独立入口和边界时分组；普通网格无需每行都套组。见[分组](./epg-group)。

## 焦点隐藏或卸载以后怎么办

下一次方向操作会优先在原分组内恢复；原组不可进入时才回到页面入口。切换页面后需要指定位置时，可在 DOM 更新完成后主动设置焦点。见[焦点项](./epg-item)。

## 原生按键怎么接入

将宿主方向、确定、返回回调连接到逻辑操作，避免同一次输入被原生回调和浏览器事件重复处理。见[原生按键接入](./native-bridge)。

## 是否提供虚拟列表或整套 TV 组件

vuEPG 提供焦点和导航能力。长列表由业务选择分页或虚拟列表，在目标项渲染后设置焦点，并按布局处理边界。页面组织建议见[性能](./performance)。
