# 工程规范

这是可以单独复制、安装和修改的 TV 网页工程。

## 工程目标

- 保留现代浏览器快速开发与旧机顶盒开发两个入口；同一套业务代码在两者中保持一致。
- 旧设备兼容组合由本工程的构建目标、依赖版本、polyfill 和浏览器回归共同定义。不能仅凭构建成功或浏览器 UA 声明兼容。
- 页面保持独立视觉与业务数据组织，按需要连接自己的服务和宿主桥。
- 用户说明围绕当前工程的功能、环境要求和操作步骤组织。

## 信息来源

| 信息                       | 应检查的来源                                   |
| -------------------------- | ---------------------------------------------- |
| 安装、开发、构建和检查命令 | package.json 的 scripts                        |
| Node / pnpm 版本           | .node-version / package.json 的 packageManager |
| Vue、vuepg 与工具版本      | package.json 和安装生成的锁文件                |
| 旧浏览器构建目标           | build-settings.cjs 与 webpack.config.cjs       |
| vuEPG API 与行为           | 已安装包的类型声明、对应版本官方文档与迁移说明 |
| 真实浏览器版本与校验       | legacy/chrome30/manifest.json                  |

Vue 或 vuepg 升级时，先查看该版本的类型和迁移说明，再调整应用代码与回归场景。不要把本文件当作任何版本的 API 手册，也不要假定示例当前用法适用于所有未来版本。

## 编码与公开内容

- TypeScript 类型必须反映真实值；不使用 any、非空断言或掩盖问题的类型断言。
- 使用箭头函数、带花括号的条件与循环、严格相等和 kebab-case 文件名。
- 注释与错误说明使用中文，标识符使用英文。错误信息以 [vuEPG] 开头。
- Mock 数据与原生模拟保持可独立运行。接入真实接口时将环境配置与业务代码分开，不把凭证、用户数据或企业内部信息写入示例。

## 构建与兼容验证

两个开发入口必须保留。Vite 用于现代浏览器，webpack 用于旧机顶盒开发与兼容构建；Vite 的生产降级能力不能替代旧设备开发服务器验证。

- 在应用及开发客户端开始工作前加载所需 polyfill，分别核对 JavaScript 与 DOM / Web API。
- 检查最终业务脚本、依赖及开发客户端的语法；仅检查源码 target 不够。
- 配色以白色／中性色为主体，vuEPG 的粉色用于焦点提示和主要按钮；预览图随视觉修改更新。
- 必要布局使用目标内核已经验证的 CSS。新增样式能力时验证旧浏览器，不因现代浏览器显示正常而认定兼容。
- 原生桥记录 Android 与浏览器键值差异，避免同一次按键被多条链路重复处理。
- 缓存、依赖、构建产物和测试结果遵守 .gitignore；独立使用时保存本项目生成的锁文件。

## 依赖升级与交互验收

API 的选择遵循实际安装版本的契约。修改或升级后，至少验证这些业务结果：

- 初始页面与异步显示内容有正确的焦点入口。
- 普通导航、业务指定跳转、循环导航与分组边界符合页面设计。
- 弹窗打开后可操作，方向键不越界，返回优先关闭弹窗，关闭后焦点落到可用位置。
- 页面切换、筛选、隐藏和卸载后焦点能够恢复，业务位置记忆保持一致。
- 实际滚动容器使焦点可见，缩放布局中的滚动距离正确。
- 事件监听、暂停持有者和定时器随业务生命周期正确释放，不出现重复输入或永久暂停。

具体生命周期钩子、API 名称、事件顺序与参数以对应版本文档为准。升级引起行为变化时同步修改应用、测试和用户说明。

## 本项目命令

在本目录运行：

```sh
pnpm install
pnpm dev
pnpm dev:tv
pnpm check
pnpm test:browser
pnpm legacy:install
pnpm test:chrome30
```

现代浏览器场景首次使用需要 `pnpm exec playwright install chromium`。真实 Chromium 30 环境需要可用的 Docker，其余浏览器依赖由项目安装。

行为修改同步相关浏览器场景；兼容配置修改同时验证 webpack 开发更新与生产入口。公开支持范围对应实际平台、浏览器和场景，设备宿主桥与性能另外记录。
